# Bright Box Homes

Custom Next.js marketing and lead-gen platform for Bright Box Homes.

## Product Lines (5)
1. **Expandable Shipping Container Homes** — 20x10 ($35,995), 20x20 ($45,995), 20x30 ($49,995), 20x40 ($59,995), 20x20 Duplex ($64,995)
2. **Apple Cabins** — 27'11" model + additional
3. **Space Capsules** — 27'11" + 37'9" models
4. **Assembly Houses** — Single + multi-unit configurations ($19,995-$25,995)
5. **Foldout Houses** — Emergency/disaster housing, base ~$2,000 + modular add-ons

## Stack
- Next.js 14 + Tailwind CSS
- Supabase (database + auth)
- Vercel (hosting + edge functions)
- Resend (transactional email)
- Cal.com (consultation booking)
- Stripe (deposits + payments)
- Rewardful (affiliate program)
